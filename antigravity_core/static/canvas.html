To sync your VIT Online progress automatically, generate a Canvas access token:

  1. Log in to lms.vitonline.in
  2. Go to Account → Settings
  3. Scroll to Approved Integrations → click + New Access Token
  4. Purpose: Antigravity Engine
  5. Copy the token and add to .env: CANVAS_API_TOKEN=your_token
  6. Restart Antigravity server
